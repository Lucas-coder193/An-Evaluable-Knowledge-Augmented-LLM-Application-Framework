# Dependencies

## 依赖注入的作用

FastAPI 的依赖注入允许路径操作声明自己需要的公共逻辑，例如共享查询参数、数据库连接或权限检查。框架会调用依赖函数，并把返回值传给路径操作；同一个依赖可以被多个接口复用。依赖的参数声明和校验也会进入 OpenAPI 文档。

## 使用 Depends

可以用 `Depends` 声明一个依赖函数。依赖函数的参数仍然按照普通 FastAPI 参数规则解析，例如 query 参数和类型校验。路径操作只接收依赖返回的结果，不需要手动调用依赖函数。

## 依赖与安全

依赖注入可以承载认证、授权、角色检查和共享资源管理。把权限检查放在依赖中，可以让多个接口共享同一套规则，同时保持请求参数和接口文档的一致性。
