## 设置响应状态码

可以在路径操作装饰器上通过 `status_code` 参数声明响应 HTTP 状态码，例如 `@app.post("/items/", status_code=201)`。它是 `get`、`post` 等装饰器方法的参数，不是路径操作函数的参数。FastAPI 会返回该状态码，并在 OpenAPI schema 中记录它。

## 常见状态码

200 表示成功，也是常见默认状态码；201 表示已创建，常用于创建新记录；204 表示无内容，响应不应包含 body。400 到 499 表示客户端错误，例如 404 表示未找到；500 到 599 表示服务端错误。

## 状态码常量

可以直接传入数字，也可以使用 `fastapi.status` 提供的常量，例如 `status.HTTP_201_CREATED`。常量值与对应数字相同，并可借助编辑器自动补全查找。
