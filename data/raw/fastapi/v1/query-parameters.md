## 参数自动识别

路径函数中，已经出现在 URL 路径里的参数会被识别为路径参数；其他函数参数会被解释为查询参数（query parameter）。查询参数位于 URL 的问号 `?` 之后，多个键值对用 `&` 连接，例如 `/items/?skip=0&limit=10`。

## 默认值与可选参数

查询参数可以设置默认值，因此可以不出现在请求 URL 中。例如 `skip: int = 0` 和 `limit: int = 10` 在省略时分别使用 0 和 10。若 URL 只提供 `skip=20`，未提供的 `limit` 仍使用默认值 10。将参数默认值设为 `None` 可使其可选。

## 类型转换与校验

给查询参数声明 Python 类型后，FastAPI 会把 URL 中的字符串值转换为相应类型，并进行校验。例如把 `short` 声明为 `bool` 后，`short=1`、`short=True`、`short=true`、`short=on` 或 `short=yes` 都可解析为 True；类型声明也支持编辑器提示和自动文档。

## 必填查询参数

非路径参数若没有默认值就是必填查询参数；设置默认值（包括 `None`）则不是必填。函数签名中的类型和默认值共同决定 FastAPI 如何解析参数、是否允许省略以及如何验证输入。
