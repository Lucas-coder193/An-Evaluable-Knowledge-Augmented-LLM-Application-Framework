## 使用 Pydantic 声明请求体

客户端需要向 API 发送数据时，可以把数据放在请求体（request body）中。FastAPI 通常使用继承自 Pydantic `BaseModel` 的类声明请求体结构，再把该模型类型声明为路径操作函数的参数。模型字段可使用标准 Python 类型。

## 模型字段是否必填

Pydantic 模型字段没有默认值时是必填字段；设置默认值后字段可省略。将字段默认值设置为 `None` 可以表达可选字段。FastAPI 会把请求 JSON 映射到模型字段，并在 OpenAPI schema 和交互式文档中展示模型结构。

## 请求体解析与校验

使用模型类型声明请求体后，FastAPI 会读取 JSON 请求体、在需要时转换类型、校验数据，并把解析后的模型对象交给函数。如果输入无效，会返回指出错误位置和内容的校验错误；模型类型还提供编辑器类型提示。

## 请求体与 HTTP 方法

发送请求体常用 POST，也可以用于 PUT、DELETE 或 PATCH。GET 请求携带请求体在规范中行为未定义；FastAPI 虽支持极少数复杂场景，但不鼓励这样做，Swagger UI 也不会显示 GET 请求体文档，且中间代理可能不支持。
